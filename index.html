integration engineering / live demo

Webhooks get lost, duplicated, and forged. Not on this route.

Relay Hub is a C#/.NET service that sits between the apps that send webhooks and the apps that need them. Every message is checked for a valid signature, stored exactly once, and delivered with retries until it lands. This page runs the same rules in your browser, using real HMAC-SHA256 through Web Crypto, with retry time sped up 4×.

    What's real here

    This page uses the same rules as the service. The real thing is an ASP.NET Core app with a SQLite database, a hosted background worker, and 19 xUnit tests.

    BehaviourIn the serviceWhere
    Forged or tampered messages are rejectedHMAC-SHA256 over the raw body, compared in fixed time, 401 on mismatchSignatureVerifier.cs
    Duplicates are processed onceUnique index on (Source, DeliveryId); a race loser gets 200 duplicateRelayDbContext.cs
    Senders never wait on receiversResponds 202 Accepted, then delivers in the backgroundProgram.cs
    Down receivers get retriedHosted worker, exponential backoff capped at 5 min, dead letter after 5 attemptsDeliveryWorker.cs
    Nothing is silently lostEvery attempt and last error recorded; any delivery can be replayeddashboard
